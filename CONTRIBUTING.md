# Working on this repository

Open an issue describing the task, intended evidence, and acceptance criteria. For shared implementation, create a short-lived branch, make a focused change, and use a pull request so the other author/team member can review it. Use direct edits on the main branch only for simple reviewed changes when appropriate.

Explain the change and its verification in each pull request. Credit the people who actually did the work and any reused/adapted software. Clearly label planned design, simulation, synthetic data, and physical measurements. Keep personal information, credentials, raw application forms and unapproved research data outside the public repository.

No open-source license is selected in this initial package. Coordinate licensing and research-data publication with the project team before adding a license or releasing restricted material.
